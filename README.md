# Calculator Ultra

A colourful calculator app (PWA) with 13 calculators, 24 themes and an editable dashboard.

## Put it on GitHub Pages
1. Create a new repository, for example `calculator-ultra`.
2. Upload everything in this folder (index.html, manifest.json, sw.js and the icons folder).
3. Go to Settings → Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Open the link GitHub gives you in Safari on your iPhone, tap Share → Add to Home Screen.

It works offline after the first visit. All history and settings stay on your phone.

## Updating later
When you upload a new version, change `VERSION` in sw.js (for example `calculator-ultra-v2`) so phones pick up the update.
